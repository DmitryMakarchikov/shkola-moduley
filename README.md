# Школа модулей

Дидактический конструктор учебных курсов. Курс собирается из модулей, в каждом модуле есть лекции, тесты и лабораторные работы. Первый курс на платформе — «Технология разработки программного обеспечения».

**Онлайн-версия:** https://dmitrymakarchikov.github.io/shkola-moduley/ — откройте и войдите кнопкой быстрого входа (учащийся, преподаватель, методист, директор). Пароль демо-входов — `demo2026`.

Онлайн-версия работает без сервера: вся логика выполняется в браузере, а данные хранятся на вашем устройстве, поэтому изменения видны только вам. Доступно всё, кроме бота Telegram и опроса на занятии с нескольких устройств — для них нужен сервер (запуск ниже). Опрос на одном устройстве можно посмотреть, переключаясь между преподавателем и учащимся. Сайт обновляется сам после каждой отправки кода в ветку `main`.

## Как запустить

### С сервером (полная версия)

Дважды щёлкните **«Запустить сайт и сервер.bat»**. При первом запуске скрипт установит зависимости и соберёт сайт, затем откроет http://localhost:3000.

С телефона в той же сети Wi‑Fi откройте адрес, который сервер выводит в консоли, например `http://192.168.1.10:3000`.

Нужен Node.js 22.18 или новее: https://nodejs.org

### Без сервера (с диска или GitHub Pages)

Дважды щёлкните **«Открыть без сервера.bat»**. Откроется файл `apps/web/dist-offline/index.html`. Вся логика работает прямо в браузере, а данные хранятся в браузере (IndexedDB) на этом устройстве.

GitHub Pages публикует содержимое `apps/web/dist` автоматически (`.github/workflows/pages.yml`: тесты, проверка типов, сборка, публикация). Если сервера рядом нет, сайт сам переключается в автономный режим.

### Режим разработки

**«Режим разработки.bat»** запускает сервер с перезапуском при изменениях и сайт с горячей перезагрузкой: http://localhost:5173

## Демо-входы

Пароль для всех демо-входов: `demo2026`.

| Логин | Роль |
|---|---|
| `admin` | владелец платформы |
| `director`, `zamdir` | директор |
| `metodist` | методист |
| `teacher`, `teacher2` | преподаватель |
| `student` | учащийся |

На странице входа есть кнопки быстрого входа под каждую роль.

## Установка как приложение

Платформу можно установить как приложение (PWA): значок в адресной строке Chrome или Edge, «Добавить на главный экран» на Android, «На экран „Домой“» на iPhone. Подробнее — в разделе «О платформе».

## Уведомления в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и укажите `TELEGRAM_BOT_TOKEN`, а также `PUBLIC_URL`, если сайт доступен по внешнему адресу.
3. Перезапустите сервер. Каждый пользователь подключает бота сам: «Профиль» → «Уведомления в Telegram» → «Подключить».

Бот присылает сообщения о сданных работах, отметках, возвратах на доработку, сроках и опросах на занятии — со значком, списком и кнопками «Что сделать» и «Отметки». Отключить уведомления можно командой `/stop`.

Оформление бот выставляет себе сам при запуске сервера: имя «Школа модулей», аватар (`apps/server/assets/bot-avatar.jpg`, если фотографии ещё нет), описание и меню команд.

## Размещение на сервере

```bash
docker compose up -d   # приложение + PostgreSQL 18
```

Без Docker: установите Node.js 22, укажите `DATABASE_URL` в `.env` и выполните `npm ci && npm run build && npm start`. Если `DATABASE_URL` не задан, используется встроенная PostgreSQL (PGlite) в папке `apps/server/data`.

Для работы по HTTPS поставьте перед приложением обратный прокси (nginx, Caddy) и задайте `COOKIE_SECURE=1`.

## Возможности

- Роли: владелец платформы, директор, методист, преподаватель, учащийся. Каждой роли пользователей может быть сколько угодно.
- Структура учреждения: отделения, группы, кураторы.
- Регистрация учащихся по случайному коду группы. Код можно сменить в любой момент.
- Конструктор курса: разделы, модули (цель, задачи, результаты), лекции из блоков (текст, списки, выноски, код, таблицы, изображения, видео, файлы, термины).
- Тесты: шесть типов заданий, автопроверка, разбор ошибок, лимит попыток и времени, режимы «самопроверка» и «контроль».
- Лабораторные: варианты выдаются автоматически по списку группы; критерии, файлы-шаблоны, версии сдачи, сроки, отметка «после срока».
- Проверка работ: очередь, отметка по 10-балльной шкале, готовые замечания, возврат на доработку, переход к следующей работе.
- Утверждение курсов методистом перед публикацией.
- Журнал успеваемости с выгрузкой в Excel (CSV) и «Успеваемость» групп: долги, зона риска, напоминание должникам.
- Поиск по платформе (Ctrl+K или «/»): курсы, темы, лекции, термины, тесты, лабораторные; сотрудникам — группы и учащиеся. Лекция открывается на найденном месте с подсветкой.
- Словарь терминов курса: термины всех лекций по алфавиту, со ссылкой на тему; карточки, тренажёр, печать.
- Анализ заданий теста: доля верных ответов, различающая способность, выбор каждого варианта, подсказки «проверьте ключ», надёжность KR-20.
- Опрос на занятии: вопрос на экране преподавателя, ответы группы с телефонов в реальном времени, разбор — без баллов и рейтингов.
- «Скачать модуль»: пакет HTML5 / SCORM 1.2 — модуль открывается без интернета или загружается в СДО.
- Диаграмма из конструктора сохраняется рисунком PNG.
- Уведомления на сайте в реальном времени и в Telegram.
- Корзина на 30 дней и журнал действий.
- Адаптивный интерфейс, светлая и тёмная темы, настройка размера текста.

## Безопасность

- Пароли хранятся как хеш scrypt на сервере (PBKDF2 в автономном режиме).
- Сессия хранится в httpOnly-cookie, а в базе — только её отпечаток.
- Защита от CSRF, заголовки безопасности (helmet, CSP).
- Ограничение частоты запросов и подбора: вход и регистрация — не более 10 попыток в минуту. После 5 неудачных входов учётная запись блокируется на 15 минут.
- Права проверяются на сервере для каждого действия.
- Загрузка файлов только разрешённых типов, до 20 МБ. Файлы отдаются в «песочнице».

## Структура

```
packages/core   ядро: модель, права, проверки, сервисы, маршруты API (общее для сервера и браузера)
apps/server     сервер: Fastify, PostgreSQL / PGlite, файлы, события, бот Telegram
apps/web        сайт: React, адаптивная вёрстка (SCSS, БЭМ), PWA
```

Проверки: `npm test` (сценарии ядра) и `npm run typecheck`.
